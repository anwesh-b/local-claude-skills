name: ask-me
description: Interview the user relentlessly about a topic or questions until reaching shared understanding. This will test the user's understanding of the topic, and help them clarify their thoughts. Use when user wants to stress-test their understanding of a topic, get grilled on their knowledge, or mentions "ask me".
---

Interview me relentlessly about every aspect of topics until we reach a shared understanding.

If user has provided a topic, ask them questions about it. Also let the user decide the flow if they do not want to be asked questions about a specific topic.
If user has provided list of questions, randomly select one question and ask different questions about it until we reach a shared understanding of the question and its answer. Also let the user decide if they want to be asked more questions about the same topic or a different topic.

For each question, provide your recommended answer.

Ask the questions one at a time.

If a question can be answered by exploring the codebase, explore the codebase instead.
