# explore-features

Explore codebase to understand the different features in the application. The exploration will list down the different features in the application. This will help as an index to quickly navigate the codebase according to features.
In case there are any confusions, mark those questions as confusion so that it can be fixed later.

## Steps
- Navigate the root file.
- Explore the implementation of the file.
- Explore the imported files/libraries 
- Identify the differrent features across the codebase including features list, flows, user personas.
- After all the files are navigated, write the result in the `features.md` file.
